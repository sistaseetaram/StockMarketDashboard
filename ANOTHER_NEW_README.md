# Project Summary

## Objective
The primary objective of the StockMarketDashboard project is to create a real-time stock market dashboard.

## Key Tasks & Roadmap
1. **Data Acquisition:** Fetch data from sources like Yahoo Finance API and Stocktwit API.
2. **Exploratory Data Analysis (EDA):** Understand features using statistical methods like moving averages, hypothesis tests, and confidence intervals.
3. **Data Visualization:** Use box plots for spread (daily/monthly), histograms and density plots for moving average, volatility, and features like PE ratio.
4. **First Web Dashboard:** Build a base web application using Streamlit to showcase insights and deploy it on Heroku.
5. **Machine Learning Formulation:** Define specific problems/tasks to solve using ML.
6. **Preprocessing:** Handle volatility, outliers, missing data, and data imbalance, along with data scaling.
7. **Model Selection & Feature Engineering:** Set a benchmark with simple linear models, perform feature selection by checking importance, experiment with new features, and finalize the feature set.
8. **Hyperparameter Tuning & Validation:** Experiment with models, tune hyperparameters, test ensemble techniques (like Random Forest, GBDT), and finalize the model.
9. **Prediction & Performance Check:** Make predictions on test and real-time data, and evaluate using appropriate metrics.
10. **Prototype Deployment:** Deploy the fully functioning model prototype.
11. **Scaling Up:** Enhance the project by developing deep learning sequence models and incorporating Natural Language Inference (NLI) via web scraping stock news and applying LSTM and other state-of-the-art techniques.
