# StockMarketDashboard Summary

## Objective
The main objective of this project is to create a real time stock market dashboard.

## Task Summary
Here is a summary of the tasks involved in the project:
1. **Data Acquisition**: Fetching data from sources like Yahoo Finance API and Stocktwit API.
2. **EDA (Exploratory Data Analysis)**: Understanding features using statistical methods.
3. **Data Visualization**: Creating box plots, histograms, and density plots to show stock price spreads, moving averages, and volatility.
4. **First Web Dashboard**: Building the base web application using StreamLit and deploying it on Heroku.
5. **Machine Learning Problem Formulation**: Identifying tasks that can be solved using ML.
6. **Preprocessing**: Dealing with data volatility, outliers, missing data, imbalance, and scaling.
7. **Model Selection and Feature Engineering**: Using simple linear models as benchmarks, checking feature importance, and finalizing features.
8. **Hyperparameter Tuning and Validation**: Experimenting with models and ensembles (like Random Forest, GBDT), and finalizing the model.
9. **Prediction on Test Data**: Predicting results and checking performance with appropriate metrics.
10. **Prototype Model Deployment**: Deploying the fully functioning prototype.
11. **Scaling up the Model**: Adding functionalities like sequence models (Deep Learning) and Natural Language Inference from stock news using LSTM techniques.
